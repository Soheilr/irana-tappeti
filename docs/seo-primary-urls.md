# URL primari SEO multidominio

## Pagine principali per i servizi locali

- https://tappeti-irana.com/lavaggio-tappeti/
- https://tappeti-irana.com/riparazione-tappeti/
- https://tappeti-irana.com/noleggio-tappeti-milano/
- https://tappeti-irana.com/tappeti-persiani-milano/

Esistono pagine con intenti simili anche su:

- https://tappeto.online/
- https://carpetarian.com/

Prima del lancio, per ogni pagina esterna con intento simile bisognerà scegliere una delle seguenti strategie:

- mantenimento con intento differente;
- contenuto sintetico con link;
- canonical;
- noindex;
- redirect, quando appropriato.

In questo step non viene modificato alcun sito esterno e la preview GitHub Pages rimane `noindex,follow`.
